# Khin Thuzar Home Karaoke Remote

Remote control PWA for Khin Thuzar Home Karaoke.

## Features

- YouTube karaoke search
- Add songs to queue
- Queue management
- Remote control for Karaoke TV App
- Supabase realtime synchronization
- Installable PWA

## Apps

This repository contains the Remote App.

The TV Player App is maintained in a separate repository.

## Built With

- React
- Vite
- Supabase
- YouTube Data API v3
- Netlify
